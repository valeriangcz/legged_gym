# QP 足端力优化数学表达整理需求

请帮我把下面的六足机器人足端力分配问题整理成严格、清晰的数学表达形式，包括变量定义、坐标系、目标函数、等式约束、不等式约束、矩阵形式，以及从足端力到关节力矩和位置增量的关系。

## 背景

机器人是六足爬壁/攀爬机器人，每条腿有 3 个主要关节和 1 个吸盘姿态关节。当前已有运动学规划会在每个控制周期生成每条腿的期望足端轨迹，并通过逆运动学得到 `q_des`。

现在希望在 `GetJointAngles` 里加入一个力学修正：

1. 先根据运动学轨迹得到初始 `q_des`。
2. 对支撑腿求解足端接触力 QP。
3. 将每个支撑足端力通过雅可比转化为关节力矩。
4. 再把力矩或等效关节力反馈转化为 `q_des` 的小增量。

已有代码约定：

- 机体系/身体坐标系记为 `B`。
- 第 `i` 条腿足端位置为 `p_i in R^3`，在 `B` 系下表达。
- 第 `i` 条腿足端接触法向量为 `n_i in R^3`，在 `B` 系下表达，已归一化。
- `self.gaits[i] == True` 表示第 `i` 条腿是支撑腿。
- `self.adhesions[i] == True` 表示第 `i` 条腿吸附。
- 运动学雅可比满足 `p_dot_i = J_i(q_i) q_dot_i`。
- 足端力到关节力矩采用 `tau_i = J_i(q_i)^T f_i`。

## 希望建立的 QP

设支撑腿集合为：

```text
S = { i | self.gaits[i] = True }
```

对每个支撑腿 `i in S`，优化变量是足端接触力：

```text
f_i in R^3
```

所有支撑腿力堆叠为：

```text
x = [f_1^T, f_2^T, ..., f_m^T]^T in R^(3m)
```

其中 `m = |S|`。

## 目标函数

希望每个足端力尽量小，目标函数为支撑足端力二次方和：

```text
minimize sum_{i in S} ||f_i||^2
```

也可以考虑加入权重：

```text
minimize sum_{i in S} w_i ||f_i||^2
```

请写成标准 QP 形式：

```text
minimize 1/2 x^T H x + g^T x
```

## 外力

外力包括：

1. 重力 `F_g`，作用点可先设为机器人质心 `p_com`。
2. 摆动腿通过当前关节力矩估算出的末端力。对摆动腿集合 `U`，估算得到足端力 `f_swing_j_est`。

我的设想是把摆动腿估算出的末端力取反，作为外界作用在机器人上的力，作用点在对应摆动腿末端：

```text
F_ext_j = - f_swing_j_est
```

请帮我判断并在数学表达中明确：

- 如果 `f_i` 定义为“环境对机器人足端的力”，外力符号应该如何写。
- 如果 `f_i` 定义为“机器人对环境的力”，外力符号应该如何写。
- 推荐采用哪一种定义，使 `tau_i = J_i^T f_i` 的符号最清楚。

## 静力平衡约束

希望满足所有力合力为 0、合力矩为 0：

```text
sum_{i in S} f_i + sum external_forces = 0
sum_{i in S} (p_i - p_ref) x f_i + sum external_torques = 0
```

其中 `p_ref` 可以取质心 `p_com` 或身体坐标系原点。

请整理成矩阵形式：

```text
A_eq x = b_eq
```

并给出每个块矩阵的含义，尤其是叉乘矩阵 `[r_i]_x` 的写法。

## 吸附和摩擦约束

每个支撑足端都有接触法向量 `n_i`。希望约束每个吸附足端：

1. 法向分量满足吸附能力约束。
2. 切向力满足摩擦锥约束。

我当前的语言描述是：

```text
每个吸附足端腿部对外界的作用力在法向量的分量减去吸附力大于等于 0；
同时减去得到的压力乘 miu 小于等于这个方向水平的分力大小。
```

请帮我严格判断这里的符号和不等号是否正确。请分别给出：

- 当 `f_i` 表示环境对机器人作用力时的约束。
- 当 `f_i` 表示机器人对环境作用力时的约束。

期望摩擦约束表达类似：

```text
||f_t_i|| <= mu_i * available_normal_i
```

其中：

```text
f_n_i = n_i^T f_i
f_t_i = f_i - f_n_i n_i
```

请说明 `available_normal_i` 应该是压力、吸附余量，还是压力加吸附力，并给出物理合理的表达。

如果严格二阶锥约束不适合 QP，请给出线性化摩擦金字塔近似，例如选取两个切向单位向量 `t_i1, t_i2` 后写成多条线性不等式：

```text
|t_i1^T f_i| <= ...
|t_i2^T f_i| <= ...
```

并写成：

```text
A_ineq x <= b_ineq
```

## 从足端力到关节修正

请整理：

```text
tau_i = J_i(q_i)^T f_i
```

以及如何将 `tau_i` 转为 `q_des` 增量的几种可选形式：

1. 简单比例：

```text
delta_q_i = K_tau tau_i
q_des_i_new = q_des_i + delta_q_i
```

2. 阻抗/柔顺形式：

```text
delta_q_i = K_q^{-1} tau_i
```

3. 加入限幅和滤波：

```text
delta_q_i = clip(delta_q_i, -delta_q_max, delta_q_max)
```
